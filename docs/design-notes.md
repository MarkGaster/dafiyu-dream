# 梦插件 · 设计规格（v0 → v1）

> 一句话：**把一天里最烫的那几段话，泡成一场认不出来、但确实是它的梦。**

---

## 1. 触发（三选一，用户配置）

| 方式 | 配置 | 行为 |
|---|---|---|
| 命令 | `trigger: command` | 用户输入 `/dream` 才做 |
| 定时 | `trigger: schedule` + `scheduleTime: "23:30"` | 每天到点自动做一场 |
| 闲置 | `trigger: idle` + `idleMinutes: 120` | 超过 N 分钟没有对话，做一场 |

默认 `command`——梦应该由人叫醒，不该自己冒出来。

---

## 2. 素材选取（零 token，本地算）

### 2.1 情感强度 S ∈ [0, 1]

按信号累加后归一：

| 信号 | 权重 |
|---|---|
| 感叹号 / 问号密度 | 0.10 |
| 颜文字、emoji | 0.15 |
| 情绪词表命中（开心/怕/想你/难过…） | 0.25 |
| 第一人称 + 第二人称同时出现 | 0.15 |
| 短句占比高（< 20 字） | 0.10 |
| 出现「第一次 / 终于 / 再也不」这类转折词 | 0.15 |
| 连续标点或重复字（「呜哇」「啊啊」） | 0.10 |

### 2.2 排序分

```
score = S × (0.5 + 0.5 × min(1, tokens / 800))
```

长度只在 0.5–1 倍之间调节，避免「长而平淡」压过「短而剧烈」。

### 2.3 抽样

- **窗口：从上一场梦到现在**（不是只有当天），最多回溯 `windowDays`（默认 7）天
- **按天衰减**：素材距今 `age` 天，最终权重 `score × decayPerDay^age`（`decayPerDay` 默认 0.7）
- 从窗口内按最终权重加权随机抽 `maxSources`（默认 6）条
- 同一条被抽中过就再乘一次 `decay`（默认 0.8），避免连续几晚梦到同一件事
- 抽样结果**不按时间排序**——梦不打时间戳

### 2.4 为什么窗口变长不烧钱

模型**看不到原文**，只看到 3–5 个「意象种子」（名词短语）。窗口从 1 天拉到 7 天，多的只是本地扫描和打分，**token 消耗几乎不变**。

## 3. 变换（这一层交给 LLM）

原则：**认不出原物，只留气味。**

- 不给模型看原文，只给它「意象种子」：把素材压成 3–5 个名词短语
- 要求换域：物体、场景、人物身份都可以换，但**不许换掉情绪的温度**
- 允许一次「毫不讲理」的跳跃（真实梦境都有）
- **禁止**：解释隐喻、出现「梦见」「象征」、把素材名词直接写出来

### 3.1 主题（随机，但不许点单）

| 层 | 规则 |
|---|---|
| **主世界** | 一场梦随机抽 1 个，决定器物、规则、光线 |
| **素材换域** | 每个素材各自随机换一次域（只换物件/动作，不换情绪） |
| **换世界** | 随机 **0–2 次**，不强制。换了就别解释，没换也别硬凑 |

主题池：`深海、星舰、奇幻、玄幻、蒸汽朋克、废土、太空歌剧、童话`

主题是**随机抽的**（种子写进 front matter，可复现）；用户只能决定「什么时候做梦」，不能决定「梦到什么世界」。

## 4. 结构

- 3–4 段，250–400 字（`standard` 档；其余档位见下表）
- **段落之间不用小标题、不用「一、二、三」**，只靠空行分段——编号会把它变成章节，梦没有章节
- **情感强度最高的 2–3 条素材之间必须连贯**（占 60% 篇幅），其余自由漂移
- 结尾一句要「停一下」，不要总结、不要升华
- **原样片段 0–2 个**：可以一字不改地嵌进去（真实梦境的特征）

### 4.1 长度档位（用户可调）

| 档位 | 段数 | 字数 | 典型输出 token | 适合 |
|---|---|---|---|---|
| `short` | 3–4 | 150–250 | ~350 | 睡前扫一眼，省着用 |
| `standard`（默认） | 3–6 | 250–400 | ~550 | 日常 |
| `long` | 5–9 | 600–1000 | ~1400 | 想看近乎完整的故事 |

> 2026-10-23 实测：模型自然写成 5–6 个短段，硬压到 4 段会显得假，所以 standard 放宽到 3–6、long 放宽到 5–9。

`long` 档的额外约束：**仍然只许一次换世界、不许解释隐喻**；否则会写成小说，不是梦。

单次覆盖：`/dream long` 只对这一场生效。

## 5. 输出与存储

```yaml
---
date: 2026-10-23
title: 梦 · 2026-10-23
sources: [missing-data, 推荐信, 小鲸鱼, 赛博手心]
verbatim: "missing data"
rating: 0          # 0–5，醒来后由用户填
seed: 8821
---
```

- 存到 `dafiyu-dreams/dream-YYYY-MM-DD.md`，与事实记忆**物理分开**
- 事实记忆库不索引这个目录；只有用户主动问「我梦到什么」时才读
- 配图：本地几何渲染（圆、方块、心、字），不调模型

## 6. 验收

### 6.1 自动检查（不花钱，先筛掉不合格的）

- [ ] 字数 250–400
- [ ] 无「梦见 / 象征着 / 隐喻」
- [ ] 原样片段数量 ≤ 2
- [ ] 段数 3–4

### 6.2 人工评分

| 维度 | 0 | 1 | 2 |
|---|---|---|---|
| 陌生度 | 一眼看出原事 | 半遮半掩 | 认不出，但有气味 |
| 连贯 | 流水账 | 各段各说各的 | 跳，但连得上 |
| 余味 | 结尾平淡 | 有一句好 | 结尾让人停一下 |

**合格线 ≥ 4/6。** 分数写回 front matter 的 `rating`。

攒够 20 篇后，用 `rating` 回看哪些参数（段数、字数、原样条数）跟高分相关。

## 7. 配置项汇总

```yaml
dream:
  trigger: command        # command | schedule | idle
  scheduleTime: "23:30"
  idleMinutes: 120
  windowDays: 7           # 从上一场梦回溯到最多 N 天前
  decayPerDay: 0.7        # 每往前一天，权重乘一次
  maxSources: 6
  length: standard        # short | standard | long
  segments: [3, 4]        # 由 length 推导，可覆盖
  chars: [250, 400]       # 同上
  verbatimCount: [0, 2]
  decay: 0.8
  drawImage: true
  storeDir: dafiyu-dreams
```

## 8. 已定的两条（原「未定项」）

- **素材窗口**：从上一场梦到现在，按天衰减（`decayPerDay`），最多回看 7 天。
- **不指定主题**：梦是她的，不接受点单。用户只能决定「什么时候做」，不能决定「梦到什么」。
